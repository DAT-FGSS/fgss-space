# 中國航天航空科技成就｜fgss-space

粉嶺官立中學（DAT）教學用靜態網頁：介紹中國航天重要里程碑、香港理工大學的參與、航天對人類的貢獻，以及香港回歸祖國三十周年（1997–2027）紀念訊息。

## 本機預覽

解壓或進入本目錄後，用瀏覽器直接開啟 `index.html` 即可（純靜態，無需伺服器、無需上網）。

```
fgss-space/
├── index.html
├── styles.css
├── app.js
├── assets/
│   └── logo-crest.png
└── README.md
```

## 部署到 GitHub Pages（DAT-FGSS/fgss-space）

1. 在 GitHub 建立（或使用已有）組織／帳戶下的倉庫：`DAT-FGSS/fgss-space`。
2. 將本資料夾內容推送到該倉庫的 `main` 分支（或預設分支）。
3. 倉庫 **Settings → Pages**：
   - Source：Deploy from a branch
   - Branch：選 `main`（或你的預設分支）
   - Folder：選 **/ (root)**  
     （若你把網站放在 `docs/`，則選 `/docs`）
4. 儲存後稍等片刻，網站網址一般為：  
   `https://dat-fgss.github.io/fgss-space/`  
   （實際網域以組織設定為準。）

本專案為本機交付版本，**不自動建立或推送 GitHub 倉庫**；由教師／維護者自行上傳部署。
